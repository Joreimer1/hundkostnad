#  Hundkalkylatorn – Vad kostar en hund på riktigt?

En guidad, interaktiv och verklighetsförankrad webbapplikation i modern skandinavisk design för att beräkna den faktiska kostnaden för hundägande i Sverige.

---

##  Vad som ingår

- **index.html**: Semantisk HTML5-struktur, hjälpsamma förklaringar och modern presentation.
- **style.css**: Skandinavisk design i skogsgrönt, bärnsten och krämvitt med full mobilanpassning och print-stöd.
- **app.js**: Dynamisk beräkningsmotor, förval (t.ex. Stockholms-Yorkie) och URL-delning.
- **assets/dog-hero.jpg**: Fotorealistisk bild med Yorkshire Terrier och Golden Retriever.
